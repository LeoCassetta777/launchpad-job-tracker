🔔 Reminders: email & phone push

Checked every 15 minutes while Launchpad is running. Nothing is sent between 10 PM and 7 AM. Each reminder goes out once.

ReminderHow

Each opportunity can override its deadline reminders in its drawer (Status → Deadline reminders).


    


    

      Set up email (Gmail app password)
      
    
        
  1. In your personal Gmail account, turn on 2-Step Verification (Google Account → Security). App passwords only work with it on.
    2. 
        
  2. Open myaccount.google.com/apppasswords, name it “Launchpad”, and click Create.
    3. 
        
  3. Copy the 16-character password. In .env, paste it after GMAIL_APP_PASSWORD= (spaces are fine), set GMAIL_ADDRESS= to that Gmail, save, and restart Launchpad.
    4. 
        
  4. In your school Outlook, add your Gmail address to Safe senders (Settings → Mail → Junk email) so reminders don't land in Junk. Optionally make a rule for subjects starting with [Launchpad].
    5. 
        
  5. Click Send test email.
    6. 
      

      
If you change your Google password, Google cancels app passwords; make a new one.

    

    

      Set up phone push (ntfy)
      
    
        
  1. Install the free ntfy app on your phone (App Store / Google Play).
    2. 
        
  2. In .env, copy the value after NTFY_TOPIC=. It's long and random on purpose: anyone who knows it could read your pushes, so it isn't shown here.
    3. 
        
  3. In the ntfy app tap + (Subscribe to topic), paste it, and keep the server as ntfy.sh.
    4. 
        
  4. Click Send test push.
    5. 
      

      
Pushes stay vague (“Deadline in 2 days — open Launchpad”); the details are only in email and here.

      How to add or change the API key
      
    
        
  1. Open the .env file in the Launchpad folder in VS Code.
    2. 
        
  2. Paste your key after ANTHROPIC_API_KEY= (no quotes, no spaces).
    3. 
        
  3. Save, then restart Launchpad (Ctrl+C in its terminal, then python app.py).
    4. 
      

      
Keys come from console.anthropic.com → API keys. Model names are in .env too (PARSE_MODEL, SMART_MODEL).
